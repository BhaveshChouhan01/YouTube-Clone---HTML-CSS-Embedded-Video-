# YouTube Clone - HTML, CSS, & Embedded Video 🎬

A responsive YouTube clone with functional video playback on thumbnail click. Built with **HTML5** and **CSS3**, this project mimics YouTube's UI and demonstrates dynamic content loading through embedded videos.

## Features ✨
- **Homepage Layout**: Replicates YouTube's grid layout with video thumbnails, titles, and channel details.
- **Video Playback**: Clicking a thumbnail opens a video player with an embedded YouTube video.
- **Hover Effects**: Smooth transitions on thumbnails and buttons.

## How It Works 🔍
- Thumbnails are linked to embedded YouTube videos.
- Clicking a thumbnail navigates to a youtube page.
- No JavaScript required! Pure HTML/CSS for navigation and styling.
